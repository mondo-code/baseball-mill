# Baseball Mill - a simple baseball sim game in C

Baseball Mill is inspired by the browser game [Baseball Century](https://baseballcentury.com/), this is my attempt at making something similar as a desktop application.

### Requirements
- C compiler (preferably gcc)
- make
- SDL2

### Build 
Run make to build. The executable will be compiled into the ./bin directory.

This is a hobby project intended for my own usage, and has been developed on Linux (with glibc) in its entirety. I don't aim to support other platforms that I don't use, and while this probably will at least compile on other Unix-like systems I can't make any promises.
